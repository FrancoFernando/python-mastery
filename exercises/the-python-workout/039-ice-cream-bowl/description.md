# Exercise 39: Ice Cream Bowl

## Description

In the previous exercise, we created a Scoop class that represents one scoop of ice cream.
If we’re really going to model the real world, though, we should have another object into which we can put the scoops. Create a Bowl class, representing a bowl into which we can put our ice cream.

## Learning

- *args packs the positional arguments into a tuple
- extend method in list appends all elements from any iterable (including tuples) to the list in one call
