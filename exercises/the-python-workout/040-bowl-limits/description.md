# Exercise 40: Bowl Limits

## Description

Modify the solution to the previous exercise. You can add as many scoops in each call to Bowl.add_scoops as you want, and you can call that method as many times as you want, but only the first three scoops will actually be added. Any additional scoops will be ignored.

## Learning

- You can define class variable inside a class but outside methods. they are the same for every instance of the class and you must refer to them as class_name.variable_name
